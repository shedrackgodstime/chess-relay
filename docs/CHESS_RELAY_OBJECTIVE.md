# Chess Relay

## Objective

Chess Relay is a multiplayer 3D chase game built in Rust for both desktop and mobile platforms.

The goal is simple:

- Players join a match and compete in a fast-paced chase environment.
- One player becomes the chaser while others attempt to escape.
- Players must use movement, positioning, and quick decisions to survive and win.
- Multiplayer gameplay is a core part of the experience, with networking designed around low-latency communication.

## Project Vision

This project serves as:

- A learning journey into game development.
- A practical exploration of multiplayer game architecture.
- A showcase of Rust for game development, networking, and systems programming.

## Current Focus

Build a fun and playable game first.

Priorities:

1. Player movement
2. Camera system
3. Core chase mechanics
4. Multiplayer gameplay
5. Mobile and desktop support

Everything else can be improved over time.
